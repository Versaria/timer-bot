# Руководство по внесению вклада

Благодарим за интерес к проекту Timer Bot! Вот как вы можете помочь:

## Отчеты об ошибках

1. Проверьте, не была ли ошибка уже зарегистрирована в Issues
2. Используйте шаблон отчета об ошибке
3. Включите шаги для воспроизведения ошибки
4. Опишите ожидаемое и фактическое поведение
5. Укажите версию Java и ОС

## Предложения улучшений

1. Опишите проблему, которую решает ваше предложение
2. Предложите конкретное решение
3. Объясните, почему это улучшение полезно

## Процесс разработки

1. Форкните репозиторий
2. Создайте ветку для вашей функции (`git checkout -b feature/amazing-feature`)
3. Сделайте коммит изменений (`git commit -m 'Add amazing feature'`)
4. Запушьте ветку (`git push origin feature/amazing-feature`)
5. Откройте Pull Request

## Стандарты кода

- Следуйте Java Code Conventions
- Пишите комментарии к сложному коду
- Добавляйте тесты для новой функциональности
- Обновляйте документацию
- Проверяйте сборку с помощью `mvn clean compile`

## Коммиты

Используйте понятные сообщения коммитов:
- `feat: добавлена новая команда /remind`
- `fix: исправлена обработка времени`
- `docs: обновлен README.md`
- `refactor: улучшена архитектура утилит`
- `ci: настройка GitHub Actions`
